## 3. 这轮踩到的坑（下次别再踩）

1. **Unity 的 `weights[k]` 要配 `boneIndexRaw[k]`**（后者是 `m_Bones` 下标），不是"第 k 个权重配第 k 根骨"。
2. **根 transform 的 `m_Father = 0/None`**：当成"编号 0 的骨"会写出悬空父骨，spine-cpp 一加载就 `0xC0000005`。
3. **加权 mesh 的权重个数必须恰好等于 `bones` 列表长度**（Spine 按 `2+len(bones)` 步长读，不一致就越界）。
4. **退出 Play 必须停脚本**：协程由 `EditorApplication.update` 泵，不加判断会继续在 edit 模式里改场景。
5. **`Names="*"` 别把角色内部子物体当独立目标**（否则隔离渲染会把目标的子节点关掉，采到全空帧）。
6. **参考帧自己也会坏**：`mesh.verts` 里有 NaN、`BakeMesh` 未应用 pose 的 t=0 —— 判据前先体检。
7. **文件名别按"完整层级路径"拼**：撞 Windows 260 限制（深目标写 `_cam.txt` 会失败）。
8. **`PathLength`/内存**：大产物只走 `.skel`；连续加载骨架的审计脚本要分片。
