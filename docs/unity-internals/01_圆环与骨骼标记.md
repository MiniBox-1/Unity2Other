# tq.txt 第 1 条：出现圆环、骨骼（针状）标记

## 1.1 现象（tq.txt 原文）

> alice_skin1_fix，alice_skin1_dl_idle 人物尾巴装饰有很多圆环，和右腿有骨骼标记；
> amy_normal 腿部有针和圆环；banshee_skin1 有针和绿环；cerberus_skin1 有针和圆环；
> csperrault_skin2 有绿环。
>
> 要求：有一些图片（atlas）如果在渲染的时候没有引用不用渲染出来了，如
> `alice_skin1_dl_idle_static_6`、`amy_normal_static_3`（灰环）、
> `alice_skin1_dl_idle_static_2`（绿环）、`alice_skin1_dl_idle_static_4`、
> `amy_normal_static_2`（骨骼标记）等等，不要把这些图片放入图集，添加屏蔽选项。

## 1.2 结论

✅ **已修（2026-09-13，本轮 2026-09-16 夜复核）**。
那些"针/圆环"是 Unity **编辑器助手**（`BoneJoint / BoneNoJoint / BoneScaled /
IKControl / splineControl` 这些 gizmo 贴图）画出来的**被禁用 Renderer**
（`m_Enabled=0`，只在 Scene 视图当控制柄显示）。转换器现在**三层过滤**：

1. prefab 里 `m_Enabled=0` 且动画从不打开 → 整件不出；
2. 贴图名命中**内置屏蔽表**（上面那几个 gizmo 贴图 + `icon-*`）→ 不出；
3. `Unity 里始终禁用（SetActive=0）` 的子树 → 不出（并按名称去重）。

被过滤掉的每一条都记在产物 `_static_info.json` 的 `excludedParts[]` 里，
带 `reason`（可审计，不是静默丢弃）。

## 1.4 屏蔽选项（tq.txt 明确要求"添加屏蔽选项"）

```powershell
# 追加屏蔽某个贴图（可重复）
python -m ngui2spine.static_prefab_spine <prefab> <out> --assets … --skip-texture BoneJoint

# 从文件读屏蔽表（每行一个名字，# 开头是注释）
python -m ngui2spine.static_prefab_spine <prefab> <out> --assets … --skip-texture-file skip.txt
```

默认屏蔽表就在转换器里（gizmo 那几个），所以"正常导出"已经不需要手工传参；
`--skip-texture` 是给"还想额外屏蔽美术废件"用的。
