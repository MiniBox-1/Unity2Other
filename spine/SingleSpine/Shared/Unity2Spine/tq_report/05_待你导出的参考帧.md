## 怎么填（一次填多个角色/状态/时刻都行）

| 字段 | 填法 |
| --- | --- |
| 角色名 | 逗号分隔，例如 `bheur_skin1,brownie_skin1`；**留空** = 场景里所有 2DModel 角色 |
| 状态名 | 逗号分隔，例如 `Lobby,breast`；**留空** = 该 Animator 的所有状态 |
| 时刻/秒 | 逗号分隔，例如 `0,0.5,1`；**是秒**，不是归一化比例（工具内部会按 clip 时长换算） |
| ppu | 640（脸局部看不清就调到 1280） |
| 写网格顶点 | 勾上（几何对账要用；文件会大一些） |

输出目录（默认写到工程根，**不会污染 Assets**）：

```text
D:\VB\Search\NormalLocal\lastOrign\_refshot_<角色>\
    frames\<角色>__<状态>__t<毫秒>.png        ← 我要看的同帧渲染
    frames\<角色>__<状态>__t<毫秒>_cam.txt    ← 相机参数（cx/cy/size/ppu）
    <角色>__<状态>__t<毫秒>.json              ← 同帧逐渲染器数据
```

## 我用它来干什么

1. 用 `frames/*.png` 对**同帧**：把我们的渲染和它对上（渲染命令我用
   `tools/rt_frames.py`，注意 `--times` 是**归一化比例 = 秒/时长**）；
2. 用 JSON 里的 `activeSelf/activeInHierarchy/enabled` 当**显隐真值**，
   用 `camDepth` 判"谁盖谁"，用 `boundsCenter/boundsSize` 对几何
   （脚本 `_scratch/editor_vis_check.py` 已经能吃这种 JSON，我会补一个
   `_refshot_*` 版本）；
3. 拿到之后我会把 2.1 / 2.3 / 2.4 / 3.3 / 3.4 直接改到闭环，并把结论回填到
   `02_运动错位.md` / `03_图片错位.md`。
