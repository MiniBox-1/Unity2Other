# 打包说明（2026-09-19）

**目的**：把「文档 + 代码 + 逆向资料」打成一个 7z，方便换一台机器继续做，
**不带**测试实例、中间数据、待废弃内容，也**不带**本地 Unity 工程。

## 换机器后怎么开工（三步）

```powershell
# 1) 解包（示例）
& "D:\7z\7-Zip-Zstandard\7z.exe" x Unity2Spine_code_docs_20260919.7z -oD:\VB

# 2) 环境（Python 3 + Pillow + numpy；渲染另需查看器 venv）
cd D:\VB\Unity2Spine
$env:PYTHONIOENCODING="utf-8"; $env:PYTHONUTF8="1"
python -m ngui2spine.static_prefab_spine --help      # 兼容层能跑 = 环境 OK

# 3) 读数：先看这两份
start 使用与代码导览.md        # 代码是什么 / 命令怎么抄
start docs\交接与核查.md        # 手段 / 铁律 / 四步校验 / 下一步
```

> 需要 Unity 工程时：把 `unity_editor_scripts\{Editor,Script,PlayModeProbe}\` 连同 `.meta`
> 拷进工程对应目录（GUID 要保留），再把 `Script\ExportRoots.cs` 的导出根指到你的 `info\`。

## 打包命令（复现用）

```powershell
& "D:\7z\7-Zip-Zstandard\7z.exe" a -t7z -m0=lzma2 -mx=7 -mmt=on `
  "D:\VB\Unity2Spine_code_docs_20260919.7z" "D:\VB\Unity2Spine" `
  -xr!_probe50_rt4 -xr!info -xr!samples -xr!_待删除_20260919 `
  -xr!_fix_spriteswap_before -xr!_c_exp_before -xr!_alice2_multi -xr!__pycache__
```

（用 `lzma2` 而不是 zstd：标准 7-Zip 也能解，换机器更保险。）
