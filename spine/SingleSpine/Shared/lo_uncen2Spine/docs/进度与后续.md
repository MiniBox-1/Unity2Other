## 一、当前进度（已完成并有证据）

### 1. 目录分区（环境 / 原代码 / 依赖 / 设定 / 文档 / 杂项 / 例子 全部分开）

```
lo_uncen2Spine\
├─ .u2s_root            项目根标记（代码靠它认根；随 exe 放一份）
├─ main.py              唯一入口：GUI / CLI（--cli）
├─ run_gui.bat  run_cli.bat  build_nuitka.bat   （ASCII 注释，bat 在 GBK 下不乱码）
├─ pyproject.toml       依赖声明（Pillow + numpy；GUI 另需 PySide6）
├─ src\     ①原代码：unity2spine\（官方库+协议+GUI+CLI） ext_lo\ ext_bdone\（两个扩展库）
│                    unity2spine_compat\、ngui2spine\（老名兼容） tools\（命令行工具）
├─ env\     ②环境：.venv-build\（uv 独立解释器）+ requirements*.txt + README
├─ deps\    ③其他依赖：third_party\（备用 skel 写出器 exe / spine-cpp 绑定源码 / 查看器补丁） reference\
├─ config\  ④设定：lo_uncen2Spine.json（唯一"外面在哪"清单） per_char_env.txt（每角色口径）
├─ docs\    ⑤文档（含 tq_report\、历史研究长文、本文件）
├─ misc\    ⑥杂项：unity_side\（要拷进 Unity 的 C#） legacy_gui\（旧 tkinter GUI 存档）
│                    verification\（检验结果：一致性对比报告 + 代表角色清单）
├─ examples\ ⑦例子：lo 一个、bdone 一个
├─ dist\    打包产物（Nuitka 生成）        .cache\ 运行时缓存/日志（可删）
```
