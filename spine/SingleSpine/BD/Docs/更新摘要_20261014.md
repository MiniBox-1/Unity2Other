## 这一轮修掉的 4 个转换器硬伤（都是拿 Unity 真值对出来的）

1. **图集页取错**：老代码用"图集 asset 同目录第一张 png"，`res/<目录>` 里
   一个目录塞多套图集时会裁到别的服装的图上
   （实例：阿波罗/协助的 `NpcGUI624` 被裁成 `NpcGUI621`）。
   → 改走 `UIAtlas.asset → mMaterial → m_Texture` 链路。
2. **部件矩形差 1~4 像素**：手写换算和 NGUI `UISprite.drawingDimensions` 不一致
   （奇数尺寸"补 1 像素"被算进了分母；没管 widget `pivot`）。
   → 按 NGUI 源码重写（含 `mType`/`mFlip`/pivot）。
3. **漏 `m_EulerCurves`**：只读四元数曲线，欧拉角曲线整段丢——BdOne 42 个 clip
   里 37 个带这个字段，实测安洁利卡/原皮有 20 多个部件完全不动作。
   → 解析欧拉曲线并按 Unity `Quaternion.Euler`(ZXY) 转角度。
4. **`animations[x].slots` 写成了 4.x 形状**（套一层皮肤名 `default`）：
   Spine **3.8** 的 JSON 读这段是**扁平**的，写成皮名会被当槽位名；
   另外没有槽位时间线时会写一个空壳 `default` 槽，`.skel` 写出器直接报错。
   → 改扁平写法、空则不写。
