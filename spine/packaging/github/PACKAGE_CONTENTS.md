# Package contents

This GitHub-oriented snapshot includes:

- converter implementation and compatibility import layer;
- command-line, GUI and validation tools;
- route-specific handover and algorithm documentation;
- static, single-bone and multi-bone sample products;
- manifests and validation reports;
- third-party Spine 3.8 Python binding material.

It excludes:

- Unity source projects;
- the external viewer/runtime and its virtual environments;
- complete 157-role and 1148-static output collections;
- raw UnityRuntime PoseFrames/PlayFrames and large draw-order captures;
- scratch experiments, deleted pre-fix products and reverse-engineering files;
- local junctions, hard links and machine-specific caches.

The excluded full products remain in the working archive. The source snapshot
in this package is intended for a normal GitHub repository; large generated
products should be published separately as release assets or Git LFS objects.
